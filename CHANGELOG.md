# Журнал изменений

Все заметные изменения проекта описаны здесь. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по
[семантическому версионированию](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- `scripts/build.ps1`: сборка плагина и релизного архива. BepInEx 5.4.23.4 скачивается и проверяется
  по SHA-256, структура архива совпадает с релизом v0.3.
- В репозиторий добавлены оригиналы картинок, PSD-исходники, шрифт `BubbleSans-Regular.otf` и
  выгрузка таблиц локализации игры (`data/`).
- `NOTICE`, `.gitattributes`, `.gitignore`.

### Изменено

- Словарь `translation.txt` вырос с 385 до 420 строк.
- Список замены картинок `image_mapping.txt` вырос с 9 до 40 записей, `data/images/translated`
  совпадает с картинками релиза v0.3.
- Структура репозитория: код в `src/`, данные в `data/`, архив `Переводы.zip` разложен по папкам.
- Путь к игре в `.csproj` задаётся свойством `GameDir` вместо жёстко прописанного пути Steam.
- Лицензия Apache 2.0 приведена к полному тексту, поэтому GitHub её распознаёт.
- README переоформлен.

### Исправлено

- Версия плагина: в исходниках стояла `0.2`, а в собранной DLL релиза v0.3 была `2.1.1`. Теперь везде
  `0.3.0`.
- Проект не собирался из репозитория, потому что `Properties/AssemblyInfo.cs` не был добавлен в git.
