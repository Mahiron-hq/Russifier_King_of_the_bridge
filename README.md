# Русификатор для игры King of the Bridge

Приветствую. Здесь находится русификатор для игры King of the Bridge от игрока **lion.burmistrov**.

На данный момент он всё ещё на этапе разработки, но вы уже можете опробовать его. Из изображений переведена только часть книги правил, оставшаяся часть книги и секретные страницы в процессе перевода. Всё остальное уже закончено.

Разработка замедлена в связи с малым количеством свободного времени, которое отнимает учёба, но она не стоит на месте.

## Инструкция по установке

1.  **Скачайте архив** по ссылке:  
    [https://github.com/LeviBurm/Russifier_King_of_the_bridge/releases](https://github.com/LeviBurm/Russifier_King_of_the_bridge/releases)  
    *(Скачивайте именно первый в списке архив, не `Source code`)*

2.  **Распакуйте архив** в корневую папку с игрой.  
    Обычный путь для Steam:
    ```
    C:\Program Files (x86)\Steam\steamapps\common\King of the Bridge
    ```
    **Перед этим обязательно закройте игру!**

3.  **Проверьте структуру.** В итоге в папке с игрой должна получиться следующая структура файлов и папок:

    ```plaintext
    King of the Bridge/
    ├── BepInEx/
    ├── King of the Bridge_BurstDebugInformation_DoNotShip/
    ├── King of the Bridge_Data/
    ├── MonoBleedingEdge/
    ├── doorstop_config.ini
    ├── King of the Bridge.exe
    ├── UnityCrashHandler64.exe
    ├── UnityPlayer.dll
    └── winhttp.dll
    ```

4.  **Запустите игру** и наслаждайтесь русским переводом!
